什么是 GitHub Pages？

GitHub Pages 是 GitHub 提供的一项免费静态网站托管服务，可以直接从 GitHub 仓库部署网站。它非常适合托管个人网站、项目文档、博客等静态内容。

使用 GitHub Pages，你可以：

  • 免费托管静态网站
  • 使用自定义域名
  • 通过 Git 版本控制管理网站内容
  • 自动部署（每次推送代码后自动更新网站）
  • 使用 HTTPS 加密

GitHub Pages 支持 HTML、CSS、JavaScript 等静态文件，也可以通过 Jekyll 生成静态网站。

部署步骤

1 创建 GitHub 账户

如果你还没有 GitHub 账户，请先 注册一个。

2 创建新仓库

登录 GitHub，点击右上角的 "+" 图标，选择 "New repository"。

仓库名称必须遵循特定格式：你的用户名.github.io

例如，如果你的用户名是 "johnsmith"，那么仓库名应该是 johnsmith.github.io。

确保选择 "Public"（公开）仓库，因为私有仓库的 GitHub Pages 功能有限。

3 准备你的网站文件

创建一个包含你的网站文件的文件夹。至少需要一个 index.html 文件作为主页。

示例文件结构：

my-website/
├── index.html
├── about.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
    └── logo.png

4 上传文件到仓库

有几种方法可以将文件上传到 GitHub 仓库：

方法一：使用 GitHub 网页界面

在仓库页面，点击 "Add file" → "Upload files"，然后将你的网站文件拖放到上传区域。

方法二：使用 Git 命令行

如果你熟悉 Git，可以使用以下命令：

# 克隆仓库到本地
git clone https://github.com/你的用户名/你的用户名.github.io.git

# 进入仓库目录
cd 你的用户名.github.io

# 将网站文件复制到仓库目录中

# 添加所有文件到 Git
git add .

# 提交更改
git commit -m "Initial website deployment"

# 推送到 GitHub
git push origin main

5 启用 GitHub Pages

在仓库页面，点击 "Settings" 选项卡，然后向下滚动到 "Pages" 部分。

在 "Source" 下拉菜单中，选择你的网站文件所在的分支（通常是 main 或 master），然后点击 "Save"。

几分钟后，你的网站将在 https://你的用户名.github.io 上线！

6 自定义域名（可选）

如果你想使用自己的域名，可以在仓库的 "Settings" → "Pages" 部分添加自定义域名。

你还需要在域名注册商处配置 DNS 记录，将域名指向 GitHub Pages。

常见问题

GitHub Pages 是免费的吗？

是的，GitHub Pages 对公开仓库完全免费。对于私有仓库，GitHub Pages 功能有限，但 GitHub Pro 用户可以享受更多功能。

GitHub Pages 支持哪些文件类型？

GitHub Pages 支持所有静态文件类型，包括 HTML、CSS、JavaScript、图片、PDF 等。它不支持服务器端语言如 PHP、Ruby 或 Python。

网站部署需要多长时间？

通常，网站会在你推送更改后的 1-10 分钟内更新。首次部署可能需要稍长时间。

我可以使用自定义域名吗？

是的，GitHub Pages 支持自定义域名。你需要在仓库设置中添加域名，并在域名注册商处配置 DNS 记录。

GitHub Pages 有存储限制吗？

GitHub Pages 网站建议不超过 1GB。如果超过此限制，可能会收到 GitHub 的提醒。

我可以使用数据库吗？

不行，GitHub Pages 只支持静态内容。如果你需要数据库功能，可以考虑使用第三方服务如 Firebase 或结合 API 使用。
